# AI Market Dashboard — Frontend

## Что это
React фронтенд информационного дашборда по крипторынку.
Показывает свечи Binance с индикаторами, AI-комментарий к последней
закрытой свече и ленту новостей. **Не торговый терминал:** вердиктов
BUY/SELL/SKIP, уверенности, риска, позиций и кошелька на экране нет — сняты
в TASK-0001. Рамка: «триггеры, не команды». Границы — `../docs/VISION.md`.

## Стек
- React 19 + TypeScript
- Vite — сборщик
- styled-components — стили
- lightweight-charts 5.2.1 — график (свечи, линии, шкала, перекрестие, зум)
- @fontsource-variable/inter, @fontsource-variable/jetbrains-mono — шрифты
  локальными пакетами (импорт в `main.tsx`), не Google Fonts
- axios — HTTP запросы

## Типы (types/market.ts)
Зеркало `backend/src/market/market.types.ts` — интервалы, диапазоны,
`MIN_CANDLES`/`MAX_CANDLES` и формы ответов меняются в обоих файлах вместе.
- `Interval` — `1m 5m 15m 1h 4h 1d`; `Range` — `1h 4h 12h 24h 2w 1m 3m 1y`
- `isAllowed(range, interval)` — свечей в диапазоне от 12 до 5000 (как бэкенд;
  иначе он ответит 400). Порядок аргументов — диапазон, интервал; у
  `getCandles` — интервал, диапазон (как в URL)
- `nearestAllowed(range, interval)` — диапазон после смены интервала:
  допустимый остаётся, иначе ближайший по порядку вкладок (24ч→1д = 2нед)
- `MarketSeries` — ответ `/candles` (`candles` + `series`, `series[i].t ===
  candles[i].t`); `MarketView` — ответ `/view` (`latest`, `recent`, `closedAt`,
  `aiComment`)

## Ключевые решения
- Источник — закрытые свечи Binance через бэкенд, своей истории нет
  (`../docs/DECISIONS.md` 2026-10-20). Кнопки «обновить» нет: новая свеча
  приходит с опросом.
- `load()` — `getCandles` и `getView` через `Promise.allSettled`: ошибки
  графика и карточки раздельные. Упал `/view` (Groq, 502 «Binance не отдал
  свечей») — график остаётся, у карточки пометка «Карточка не обновилась: …».
  Баннер — только по ошибке свечей.
- Тексты ошибок: нет ответа — «Нет связи с бэкендом»; 502 — сообщение
  бэкенда («Binance недоступен»); другой код — «Бэкенд вернул ошибку (код N)».
- Токен запроса (`requestRef`) — поздний ответ после смены монеты,
  интервала, диапазона или следующего опроса в состояние не попадает.
- Данные показываются, только если они про текущие монету, интервал и
  диапазон (`chartShown`/`viewShown`): после переключения и отказа под
  баннером иначе висели бы чужие цены. Пока идёт запрос — скелетон.
- Скелетон загрузки (TASK-0005) — график, карточка, таблица, лента
  «Инфополе». Загрузка = данных про текущий выбор нет и ответа на него ещё
  не было (`settled` в `App.tsx`): ошибка прошлой монеты не гасит скелетон
  новой, баннер прошлого выбора висит рядом до ответа. Опрос скелетон не
  показывает. Показ — через 300 мс (`hooks/useDelayedFlag.ts`): ответ из
  кэша не мигает. Плашка — `components/Skeleton.ts`; у графика — поверх
  canvas (`z-index` выше слоёв библиотеки).
- Интервал и диапазон меняются одним обработчиком (`changeInterval`):
  React сводит оба `setState` в один рендер, недопустимая пара на бэкенд не
  уходит (замер CDP Network, TASK-0004.8: 0 ответов 400).
- Недопустимые вкладки периода погашены (`isAllowed` по текущему интервалу).
- График (`CandleChart`, TASK-0003) — lightweight-charts, создаётся в
  эффекте, `remove()` в очистке (StrictMode не двоит), `autoSize`.
  - Время — секунды UTC (`t / 1000`); ось и перекрестие подписываются
    через `formatCandleTime` в местном времени — без этого ось рисует UTC
    и расходится с таблицей. Дата — на диапазонах длиннее суток.
  - Данные — `toChartData` (`chartData.ts`): `null` индикатора — пустая
    точка, не `value: null`. Дыра между соседними свечами больше 3
    интервалов (остановка Binance) — пустая точка во всех сериях; у
    последней точки линии перед разрывом цвет `transparent`: библиотека
    соединяет точки через пустую, отрезок красится цветом левой точки.
  - BB — пунктирные `bbUpper`/`bbLower` и заливка между ними примитивом
    `bandPrimitive.ts` (`zOrder: bottom` — под сеткой и свечами).
  - `fitContent` — только при смене монеты, интервала или диапазона:
    опрос не сбрасывает зум и прокрутку.
  - Метка последней цены — своя `createPriceLine` по последней свече:
    встроенная метка серии показывает последнюю *видимую* свечу.
  - Без данных шкала цены спрятана: `setData([])` не сбрасывает её
    диапазон, на пустом графике висели цены прошлой монеты.
  - Точность 2 знака — как `round` бэкенда. Логотип TradingView
    (`attributionLogo`) — условие лицензии, оставлен.
- Легенда над графиком (`PriceChart`) — O H L C, EMA9, EMA21, BB наведённой
  свечи, иначе последней. Наведённая ищется в текущих данных по ключу
  (`seriesKey`) и `t`: после опроса легенда не прыгает, после смены монеты
  показывает последнюю.
- Одна свеча — одна подпись по времени открытия (`formatCandleTime`):
  перекрестие, легенда и таблица «19:40», карточка «свеча 5м · 19:40–19:45»;
  дневная свеча — только дата («19 окт.»), её граница — полночь UTC.
- Первая загрузка в эффекте — через `Promise.resolve().then(load)`, не прямым
  вызовом (`react-hooks/set-state-in-effect`).

## Монеты
- bitcoin  → BTC/USDT
- ethereum → ETH/USDT
- solana   → SOL/USDT

Своих цветов у монет нет — монохром (TASK-0003): второй брендовый цвет
запрещён системой, цена видна свечами.

## Опрос
- `load()` раз в `min(интервал, 5 мин) + 10 с` (план TASK-0004, trade-off 9);
  таймер не выровнен по закрытию свечи — отставание экрана от 0 до периода
- При смене монеты, интервала или диапазона — немедленная перезагрузка
- Новая свеча → новый AI-комментарий на бэкенде (кэш по фактам свечи); на
  1м — раз в минуту на монету, принято (план TASK-0004, trade-off 6)

## Известное
- Подпись цены на шкале графика — с точкой (`84127.99`), в легенде и
  карточке — `ru-RU` с запятой (замечено в TASK-0003.9).
- lightweight-charts бросает на неупорядоченных данных и дублях `time` —
  держится на порядке свечей бэкенда (`binance/klines.ts`).
- `NewsPanel` — `try/finally` без `catch`: отказ `/news` даёт пустую ленту без
  индикации ошибки. Предсуществующий дефект, отдельный тикет.

## Дизайн
Язык ClickHouse — копия `../docs/design/clickhouse.DESIGN.md` (MIT, коммит
`e06a966`); доопределения для дашборда — `../docs/aidd/plan/TASK-0003.md`.
- Литералы цвета — только в `styles/theme.ts`; в компонентах — токены
  (`canvas`, `surfaceCard`, `surfaceElevated`, `hairline`, `ink`, `body`,
  `muted`…). Без инлайн стилей.
- Жёлтый `primary` — скупо, ровно в четырёх местах: слово в шапке, цена в
  карточке, метка последней цены на графике, подпись «AI-свод». Активные
  вкладки — не жёлтые.
- Рост/падение — `up`/`down` (свечи, RSI, гистограмма MACD); `warning` —
  баннеры и регуляторные метки новостей. Серии графика — серые
  (`theme.chart`), без второго брендового цвета.
- Шрифты: Inter — текст и заголовки (700 с трекингом −0.5px); JetBrains
  Mono — числа, время, селекторы графика. На весь body — `tabular-nums`.
- Вкладки — category-tab: неактивная прозрачная `muted`, активная
  `surfaceCard` + `ink`; внутри карточки активная — `surfaceElevated`
  (иначе сливается с карточкой).
- Заголовки секций — caption-uppercase (12px, 600, трекинг 1.5px).
- Карточки — `surfaceCard` + `hairline`, `radius.lg` 12px. Теней и
  градиентов нет: глубина — контрастом канваса и карточки.
