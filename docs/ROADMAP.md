# Roadmap

Живой список. Обновляется при каждом изменении направления.
Порядок в секциях = приоритет (сверху важнее).

## Сейчас

- [ ] **TASK-0002: индикаторы считаются по мёртвым данным, график врёт** —
      первый тикет после миграции (TASK-0001 закрыта), `docs/aidd/prd/TASK-0002.prd.md`.
      `getEMA`/`getRSI`/`getMACD` берут самые старые строки `PriceSnapshot`
      (`orderBy: 'asc'`), поэтому EMA9, EMA21, RSI и MACD не менялись с мая:
      замер — по одному различному значению на 148 снимков при цене,
      ходящей 62 676…86 318. Плюс BB не нарисована полосой (`bbRange`
      считается и не используется) и местами уходит за домен Y.
      Заведён 2026-10-07 после первого живого просмотра дашборда.
      **До починки дашборд не выполняет «честную подачу» из `VISION.md`:**
      AI-комментарий добросовестно пересказывает мёртвые входы.

## Хотелки (приоритет сверху вниз)

- [ ] **Funding stress + z-score** — сигнал позиционирования толпы.
  Binance API (уже используем для бэктеста). Первый источник данных,
  который НЕ запаздывающая цена. Лучший кандидат: дёшево, сильный сигнал.
- [ ] **Market regime** — определение режима рынка (тренд / флэт).
  Контекст для чтения остальных факторов.
- [ ] **Расширенный Daily Read** — свод не только новостей, но и рыночного
  состояния (цена + объём + новости в одном абзаце). Развитие дайджеста.
- [ ] **Институциональное накопление** — ETF flows + treasuries.
  Публичные данные (не on-chain атрибуция). Новый `WhalePanel`,
  НЕ переиспользовать Wallet/Positions (разная семантика).

## Production-hardening

- [ ] `.env.example` — сейчас нет, без него проект не запустить со стороны.
  Отдельным тикетом **после** миграции: список переменных зависит от того,
  что переживёт удаление торгового ядра.
- [ ] Docker full-stack (сейчас только Postgres)
- [ ] CI: GitHub Actions (lint + build)
- [ ] Health-checks внешних зависимостей (БД, Groq, RSS)
- [ ] AI reasoning только на значимые события (экономия при постоянном сервере)
      Сейчас AI-комментарий к снимку вызывает LLM почти на каждый опрос
      фронта (~12 вызовов в час на вкладку): цена входит в хеш кэша.
      Принято как цена «комментария на лету» — `DECISIONS.md`, 2026-10-07.

## Отложено

- Polymarket-виджет — мало релевантных данных (`RESEARCH.md`).
  Крипто-рынки там: ценовые производные + новелти, событийных мало —
  порядка 1 релевантного рынка на 100.

## Отвергнуто (не возвращаться без веской причины)

- **Автоторговля** — нет edge (`RESEARCH.md`, бэктест)
- **Тех-индикаторы как автосигнал** — доказано убыточным
- **On-chain атрибуция кошельков** — дорогая инфра (Arkham/Nansen/RPC)
- **Correlation Engine на автоторговлю** — overfitting, иллюзия edge
- **Telegram как источник** — scope creep, RSS покрывает задачу
- **Автотесты UI** — false-green без реального флоу
