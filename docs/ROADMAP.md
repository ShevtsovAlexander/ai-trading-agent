# Roadmap

Живой список. Обновляется при каждом изменении направления.
Порядок в секциях = приоритет (сверху важнее).

## Сейчас

Активного тикета нет — следующий берётся из «Хотелок» или
«Production-hardening».

## Хотелки (приоритет сверху вниз)

- [ ] **Funding stress + z-score** — сигнал позиционирования толпы.
  Binance API (уже используем для бэктеста). Первый источник данных,
  который НЕ запаздывающая цена. Лучший кандидат: дёшево, сильный сигнал.
- [ ] **Market regime** — определение режима рынка (тренд / флэт).
  Контекст для чтения остальных факторов.
- [ ] **Расширенный Daily Read** — свод не только новостей, но и рыночного
  состояния (цена + объём + новости в одном абзаце). Развитие дайджеста.
- [ ] **Институциональное накопление** — ETF flows + treasuries.
  Публичные данные (не on-chain атрибуция). Новый `WhalePanel`,
  НЕ переиспользовать Wallet/Positions (разная семантика).

## Production-hardening

- [ ] `.env.example` — сейчас нет, без него проект не запустить со стороны.
  Отдельным тикетом **после** миграции: список переменных зависит от того,
  что переживёт удаление торгового ядра.
- [ ] Убрать Postgres/Prisma или найти им применение — с TASK-0004 БД
      никто не читает и не пишет: `PriceSnapshot`/`MarketSnapshot` — архив
      (`DECISIONS.md` 2026-10-20), но `PrismaService` подключается при старте
      бэкенда (`prisma.service.ts:16-18`). Без запущенного Postgres бэкенд
      стартует и всё равно пишет «Подключено к PostgreSQL» — `$connect` с
      адаптером `PrismaPg` ленивый, лог врёт. Замечено 2026-10-21 в TASK-0003.
- [ ] Docker full-stack (сейчас только Postgres)
- [ ] CI: GitHub Actions (lint + build)
- [ ] Health-checks внешних зависимостей (БД, Groq, RSS)
- [ ] AI reasoning только на значимые события (экономия при постоянном сервере)
      Сейчас AI-комментарий вызывает LLM на каждое закрытие свечи
      выбранного интервала (на 1м — раз в минуту на монету): факты свечи
      входят в хеш кэша. Принято — `DECISIONS.md`, 2026-10-07 и 2026-10-20.
- [ ] Таймаут Groq на `/market/view` — сейчас маршрут ждёт модель
      синхронно, промах кэша добавляет 1–1.7 с к ответу с ценой; варианты —
      таймаут или комментарий отдельным запросом (TASK-0004, «Замечено рядом»).

## Отложено

- Polymarket-виджет — мало релевантных данных (`RESEARCH.md`).
  Крипто-рынки там: ценовые производные + новелти, событийных мало —
  порядка 1 релевантного рынка на 100.

## Отвергнуто (не возвращаться без веской причины)

- **Автоторговля** — нет edge (`RESEARCH.md`, бэктест)
- **Тех-индикаторы как автосигнал** — доказано убыточным
- **On-chain атрибуция кошельков** — дорогая инфра (Arkham/Nansen/RPC)
- **Correlation Engine на автоторговлю** — overfitting, иллюзия edge
- **Telegram как источник** — scope creep, RSS покрывает задачу
- **Автотесты UI** — false-green без реального флоу

- **v1-trading-bot** (тег) — торговая версия с бэктестом. Доказала что
  TA не даёт edge. Основа переориентации на инфо-дашборд.
- [x] **Миграция: торговый бот → информационный дашборд** (TASK-0001,
  закрыта 2026-10-07). Торговое ядро снято (кошелёк, позиции, вердикты
  BUY/SELL — код и таблицы), слой `analyze` переименован в `market`,
  `DecisionCard` → `MarketStateCard`, таб «Торговля» → «Рынок», AI-текст —
  описание обстановки без рекомендаций. Бэктест-движок оставлен. Артефакты —
  `docs/aidd/*/TASK-0001*`. Честная подача из `VISION.md` **не достигнута**
  до TASK-0002.
- [x] **TASK-0002: индикаторы по мёртвым данным, график врёт** (закрыта
  2026-10-19). Формулы и выборка исправлены: общий модуль формул
  (`backend/src/indicators/`), RSI по Уайлдеру, EMA/RSI/MACD по свежим 100
  строкам, цена пишется до чтения индикаторов — живая проверка совпала с
  `technicalindicators` на данных БД. График: полоса BB, временная ось,
  пропуски видны разрывами. **Окно склеивает паузы — после перезапуска
  индикаторы недостоверны, чинит TASK-0004.** Артефакты —
  `docs/aidd/*/TASK-0002*`.
- [x] **TASK-0004: цены — свечи Binance по запросу, своя история не нужна**
  (закрыта 2026-10-20). Окно в 100 строк склеивало остановки бэкенда —
  индикаторы врали после каждого запуска. Вместо догрузки истории в БД
  (первая версия PRD) — закрытые свечи Binance `klines` по запросу:
  крон, `PriceService` и запись цен сняты, год истории доступен сразу.
  Селект интервала `1м…1д`, недопустимые сочетания погашены; разогрев 500
  свечей; AI видит 5 свечей с изменениями, посчитанными кодом. Живая
  проверка после часа простоя: ряды = `technicalindicators` на свечах
  Binance (152 317 значений, 0 расхождений), свежесть 12/12, баннер при
  недоступном Binance. **Честная подача (`VISION.md`) для цен и
  индикаторов достигнута**; текст AI — без оракула, неточности остались.
  Решение — `DECISIONS.md` 2026-10-20, артефакты — `docs/aidd/*/TASK-0004*`.
