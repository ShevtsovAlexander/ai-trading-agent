  `orderbook/orderbook.types.ts` (символы, `BUCKET_STEP`, `WALLS_PER_SIDE`),

  без изменений). Скрипт вне репо снимает фикстуру: сырые ответы обеих бирж

    Binance покупки — меньше 5000, `full.bid = true`); пустая/пробельная строка,

    `code`, без проверки порядка, `full` всегда false) — красные.
  - **Итог (2026-11-02):** фикстура `orderbook/fixtures/books-2026-11-02.json`
    (1,7 МБ) — шесть ответов, снятых параллельно в 11:04:07 UTC; лучшие цены
    BTC: Binance 77970.00 / 77970.01, OKX 77957.1 / 77957.2 (разрыв $13).
    SOL Binance покупки — **4691** уровень (не 4695, как в research:
    стакан живой), `full.bid = true`; остальные стороны — 5000. Ошибки:
    Binance `FOOUSDT` — HTTP 400 `{code:-1121}` (бросает axios), OKX
    `FOO-USDT` — HTTP 200 `{code:"51001"}`. Лимит OKX: заголовков лимита в

    Мутанты — 5 из 5 красные: без проверки `code` (1), без проверки порядка
    (6), `full` всегда false (1), без проверки пустой стороны (2), часы
    Binance до запроса (1).
    **Критик T1 → решения человека:** время Binance — часы после ответа
    (`clock` параметром, план «Источники» поправлен); обрезанный ответ

    «4695» → «меньше 5000»; тест на пустое тело Binance.

- [ ] **TASK-0009.2: сборка `buildWalls`**
  `orderbook/walls.ts` по контракту плана: mid, общий край, сторона от mid,
  ступени, отброс разрезанной краем ступени, сумма и `Σ цена × объём`,
  N крупнейших. Независимый скрипт (Python, вне кода бэкенда) считает
  эталон из той же фикстуры → `expected` в фикстуре.
  - Критерий готовности: на фикстуре трёх монет — совпадение с эталоном
    по всем ступеням и полям (`from`, `coin`, `usdt` ≤ 1e-9 отн., `byExchange`);
    биржа `null` — охват и стены по другой; покупки все `< mid`, продажи
    `> mid`; ни одна ступень не дальше общего края; вне топ-N нет ступени
    крупнее последней нарисованной (критерий 2 PRD).
  - Оракул: эталон независимого скрипта; мутанты (край — дальний, а не
    ближний; стороны без mid; `usdt = coin × середина`) — красные.
