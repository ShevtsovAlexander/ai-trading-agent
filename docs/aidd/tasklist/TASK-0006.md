- [ ] **TASK-0006.3: `GET /market/candles/:coinId/history`**
  `getHistory(coinId, interval, before)` по контракту плана: окно
  `HISTORY_CHUNK + WARMUP` до `before`, ряды тем же расчётом, что
  `compute`, кэш истории, `complete`, 400 на невалидный `before`, 429 от
  стража, 502 от Binance. Тип `HistoryChunk` в `market.types.ts`.
  - Критерий готовности (jest на честном фейке Binance, образец
    `market-data.service.spec.ts:90`):
    1) ряды куска = `technicalindicators` на всех close фейка (длинный ряд)
       для тех же `t` — включая первую свечу куска;
    2) кусок `before = getSeries(...).candles[0].t` стыкуется: последняя
       свеча куска = `before − step`, дублей нет;
    3) два куска подряд (`before₂ = chunk₁.candles[0].t`) — без дыр и дублей;
    4) фейк с листингом внутри окна → `complete: true`, свечи только от
       листинга, ранние индикаторы `null`;
    5) `before` не кратен интервалу / в будущем / не число → 400 без
       запроса к Binance; вес ≥ 4800 → 429 без запроса;
    6) повторный кусок — 0 запросов (кэш).
    Плюс живой: BTC 5м, 3 куска подряд — ряды = `technicalindicators` на
    свечах Binance того же отрезка (скрипт как `t8_oracle` TASK-0004);
    BTC 1д от `before` в 2018 → `complete: true`, первая свеча 2017-08-17.
  - Оракул: `technicalindicators` (эталон) + живой Binance. Мутанты:
    «без разогрева», «`t ≤ before`» — обязаны покраснеть.
