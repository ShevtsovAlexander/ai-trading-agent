# Tasklist: TASK-0008

План — `docs/aidd/plan/TASK-0008.md`. Порядок: бэкенд — источники (T1),
сборка ряда (T2), сервис и маршрут (T3), живая сверка (T4) → фронт — данные
(T5), карточка с графиком (T6) → живая приёмка (T7) → доки (T8). Каждая
задача оставляет дашборд рабочим; после бэкендовых — `npx jest`,
`npx tsc --noEmit`, после фронтовых — `npx tsc -b`, `npx eslint src`;
критик, стоп на ревью.

- [x] **TASK-0008.1: источники истории OI и mark Bybit + фикстура**
  В `sources.ts`: `fetchOiHistoryBinance` (назад по `endTime`),
  `fetchOiHistoryOkx` (назад по `end`, `1Dutc`/`1H`), `fetchOiHistoryBybit`
  (курсор), `fetchMarkBybit`. Строгий разбор, ошибки в теле, «страница не
  сдвинулась», задержка между страницами. Скрипт вне репо снимает фикстуру
  `oi-history-2026-10-28.json`: сырые ответы BTC по обоим шагам (все
  страницы) + ошибки в теле. Тот же прогон для трёх монет параллельно — замер,
  есть ли ответы лимита.
  - Критерий готовности: разбор фикстуры даёт 30/720 меток у Binance и
    Bybit и 31/721 строк у OKX на окно; пустые/пробельные/отрицательные
    значения и `code`/`retCode` ≠ 0 — ошибка источника; постраничный фейк
    честно применяет `endTime`/`end`/курсор и ловит несдвиг; итог замера
    лимитов — строкой в tasklist.
  - Оракул: реальные ответы бирж (фикстура curl); мутант (без сдвига
    страницы, без проверки кода в теле) — красный.
  - **Итог (2026-10-28):** фикстура — снимок 12:20 UTC, BTC, все страницы
    (строки старше окна на 2 дня обрезаны). На окне `capturedAt − 30 дн −
    шаг`: Binance 30 / 720, OKX 31 / 721, **Bybit 31 / 721** (не 30 / 720,
    как в критерии: у Bybit, как у OKX, есть метка на шаг старше — Binance
    упирается в свой предел 30 дней). Запросов: Binance 1 / 2, OKX 1 / 8,
    Bybit 1 / 4, mark 1 — **проверено на данных, добитых синтетикой до
    полных страниц старше окна** (критик T1: в обрезанной фикстуре выход
    шёл по концу данных, а не по `from`; мутант «без выхода по `from`» был
    зелёным — после правки красный у всех трёх бирж). Ранний обрыв ряда
    (биржа отдала короткую страницу до `from`) ошибкой не считается — даст
    дыры в T2 (решение человека). Стыки страниц (замер): Binance `endTime`
    включительно → следующая страница с `oldest − 1`; OKX `end`
    исключительно; Bybit — курсор. Binance на неизвестный символ отвечает
    `[]` без кода → «нет данных». Тесты: `sources.spec.ts` +27 (59), фейки
    честно применяют `endTime`/`end`/курсор/`limit`. Мутанты — 12 из 12
    красные: без проверки сдвига (Binance, OKX, Bybit), `endTime` без `−1`,
    ошибка-объект Binance, `code` OKX, `retCode` Bybit, обрезка mark, пустой
    итог, без выхода по `from` (Binance, OKX, Bybit). Аннотация типа `d` у
    Bybit нужна eslint, не tsc (без неё — 5 ошибок `no-unsafe-*`). Лимиты: почасовая выгрузка трёх монет параллельно, два прогона
    подряд — 90 запросов, 0 отказов; ≈ 4,5 с на монету (8 страниц OKX).

- [x] **TASK-0008.2: сборка ряда `buildOiSeries`**
  `oi-history.ts`: моменты (OKX + шаг, живая строка отброшена), окно 30 дн.,
  пересечение учтённых бирж, Bybit × mark(T), сумма, цена = close свечи,
  закрытой в T. Независимый скрипт (Python, вне кода бэкенда) считает
  эталонный ряд из тех же сырых ответов фикстуры → `expected` в фикстуре.
  - Критерий готовности: на фикстуре BTC ряд совпадает с эталоном по
    всем точкам и полям (оба шага; 30 и 720 точек); пропуск метки у одной
    биржи даёт дыру, а не сумму по двум; биржа `null` выпадает из всех
    точек; живая строка OKX не попадает; точек вне окна нет.
  - Оракул: эталон независимого скрипта на тех же данных; мутанты (без
    сдвига OKX; сумма по доступным в точке) — красные.
  - **Итог (2026-10-28):** `oi-history.ts` — `buildOiSeries`, типы `OiStep`,
    `OiPoint` в `derivatives.types.ts`. Отступление от контракта плана:
    Bybit и его mark — одним полем `bybit: { rows, marks } | null` (OI без
    цены не бывает: упала mark — сервис передаёт `null`). Эталон —
    `scratchpad/oi_oracle.py`, другой способ: сетка моментов от `now` назад,
    а не пересечение меток; `expected` записан в фикстуру. Совпадение —
    точное (`toEqual`), 30 и 720 точек, 09-29…10-28 00:00 и 09-28 13:00…
    10-28 12:00, цена у всех; последняя сумма BTC ≈ 15,41 млрд (снимок
    TASK-0007 ≈ 15,6). `oi-history.spec.ts` — 11 тестов. Мутанты 5 из 5
    красные: без сдвига OKX, сумма по доступным в точке, без правого края,
    без левого края, цена — свеча, открытая в t. Левый край сначала был
    зелёным: окно держал предел истории Binance, а не код (кандидаты —
    моменты первой биржи) — добавлен тест «Binance null», где моменты
    берутся у OKX со строками старше окна.
