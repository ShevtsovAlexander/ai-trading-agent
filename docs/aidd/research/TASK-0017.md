## Риски изменения

1. **Сдвиг метки на день** (замер выше): без сдвига точка 1Г расходится с 30Д на 1–3 % и встаёт не на ту дату в легенде.
2. **Незакрытый день в ответе** — последний бар живой, его значение меняется до 00:00 UTC.
3. **Лимит общий, пауза — нет.** `pausedUntil` — приватное поле `LiquidationsService` (`liquidations.service.ts:47`); запросы OI из другого сервиса о паузе не узнают и могут продлить 429. Лимит 40 в минуту на ключ (`:39-40`).
4. **Нет таймаута** у `HttpModule` деривативов (`derivatives.module.ts:7`); у ликвидаций — 10 с (`liquidations.module.ts:8`).
5. **Критерий полноты кэша завязан на 30 дней** (`derivatives.service.ts:250-254`): для 365 / 1502 точек — другое число.
6. **Ключ `fitContent` и опрос.** `OpenInterestChart.tsx:120` — `монета|шаг`; без периода в ключе смена 30Д → 1Г не подгонит вид.
7. **Шкала времени.** `timeVisible` только при `1h` (`OpenInterestChart.tsx:197`); на 1500 днях метки по году/месяцу уже есть (`:100-103`).
8. **SOL Binance — 2,96 %** в один день из 30: расхождение есть даже со сдвигом; на стыке 30Д / 1Г будет заметно.
9. **Спот для цены на «Всё»** — 2 страницы klines (`binance/klines.ts:6`); ограничителя у маршрута деривативов нет (см. ниже).
