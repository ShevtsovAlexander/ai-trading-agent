### PriceChart — текущее устройство (то, что переносится на lightweight-charts)

- **Входные данные** — `MarketSeries` (`types/market.ts:102-109`):
  `candles: Candle[]` с полным OHLC (`types/market.ts:76-83`: `t, open, high,
  low, close, volume`) и `series: SeriesPoint[]`, `series[i].t === candles[i].t`.
  Бэкенд отдаёт OHLC уже сейчас: `backend/src/market/market.types.ts:3-10`,
  срез `candles = all.slice(start)` — `backend/src/market/market-data.service.ts:180-182`.
  **Новых данных для свечей не нужно** — график использует только `c.close`
  (`PriceChart.tsx:231`).
- **Время** — `t` = openTime в **миллисекундах** (`types/market.ts:75`,
  `PriceChart.tsx:230`).
- **Индикаторы** округлены бэкендом до 2 знаков: `round` —
  `backend/src/market/market-data.service.ts:42-45`; `null` = периоду не
  хватило свечей (`types/market.ts:85`). На графике `null` EMA/BB в начале
  ряда сейчас просто не рисуются.
- **Разрывы**: `GAP_INTERVALS = 3` (`PriceChart.tsx:213`); дыра > 3 интервалов
  — вставка пустой точки, рвутся все серии (`:243-259`).
- **Домен Y** — по цене и BB с отступом 0.1%, цикл вместо `Math.min(...arr)`
  из-за лимита аргументов Safari на 5000 точек (`:267-282`).
- **Подписи оси X** — `ticks = points.map(p => p.t)` (каждая точка —
  кандидат) + `interval="preserveStartEnd"` (`:265, :351-356`): источник

  `$${v.toLocaleString()}` без округления (`:363`): источник «дробных
  значений оси Y».
- **Дата в подписях** — на диапазонах длиннее 24ч (`:262`); тултип зовёт
  `formatCandleTime(d.t, interval, withDate)` (`:180`).

- **Высота** — `ResponsiveContainer width="100%" height={200}` (`:344`).
- **Ширина** — график во всю ширину `TopRow` (`App.tsx:302-305`).
- **Пересоздание** — компонент без состояния и эффектов: каждый рендер

## Риски изменения

1. **Время в секундах vs миллисекундах.** У нас `t` в мс (`types/market.ts:75`);
   lightweight-charts на оси времени принимает UTCTimestamp **в секундах** —
   это знание о библиотеке, не из репозитория; проверить по её документации
   v5. Ошибка даёт график в 1970-м или в далёком будущем.
2. **UTC против местного времени.** Ось lightweight-charts по умолчанию
   рисует время как UTC (знание о библиотеке, проверить), а
   `formatCandleTime` — местное `ru-RU` (`candleTime.ts:13-17`). Без
   форматтера ось и тултип/таблица разойдутся на смещение часового пояса —
   ровно то, что запрещает «одна свеча — одна подпись».
3. **Разрывы на остановке биржи.** lightweight-charts — ось по барам, не по
   непрерывному времени (знание о библиотеке, проверить): дыра Binance
   схлопнется без видимого разрыва. Текущее решение с пустой точкой
   (`PriceChart.tsx:210-259`) — сознательное, записано в `frontend/CLAUDE.md`
   «пропуски видны разрывами» (итог TASK-0002, `docs/ROADMAP.md`). Нужно
   решить в плане, как сохранить.
4. **Полоса BB.** Сейчас — одна `Area` между низом и верхом
   (`PriceChart.tsx:371-382`). В lightweight-charts встроенной «полосы между
   двумя линиями» нет (знание о библиотеке, проверить для v5 — плагины/
   примеры). Варианты — в плане; риск потерять заливку, которую TASK-0002
   ввёл специально.
5. **`null` в начале рядов** (`types/market.ts:85`) — нельзя отдавать
   серии точки со значением `null`; нужна фильтрация или whitespace-точки.
6. **Императивный жизненный цикл.** Сейчас компонент чистый, StrictMode
   включён (`main.tsx:9`) — эффекты создания графика вызовутся дважды в
   dev; без `remove()` в очистке — два графика в контейнере. Опрос каждый
   тик даёт новый `chart` (`App.tsx:76`) — полный `setData` сбросит зум/
   прокрутку пользователя каждые `min(интервал,5м)+10с` (`App.tsx:105-108`).
   Зум и прокрутка — критерий 9 PRD.
7. **Ширина.** `ResponsiveContainer` сейчас сам следит за шириной
   (`PriceChart.tsx:344`); у lightweight-charts — своя настройка
   авто-размера (знание о библиотеке, проверить), иначе график не
   растянется при ресайзе окна.
8. **`chartShown === null`** (`App.tsx:115-121`) — при смене монеты график
   должен очиститься, а не показывать прошлую монету (`frontend/CLAUDE.md`,
   «Данные показываются, только если…»).
9. **Масштаб цены SOL** — значения ~$100–200, BTC — десятки тысяч; формат
   цены на шкале (точность) задаётся на серию. Сейчас формат один для
   всех (`PriceChart.tsx:363`).
10. **Шрифты в canvas.** lightweight-charts рисует на canvas — CSS
    `font-family` страницы на подписи осей не действует; шрифт задаётся
    опцией графика, и если веб-шрифт ещё не загрузился к первому рендеру,
    canvas нарисует fallback (знание о canvas, проверить живьём).
11. **Цвета в canvas** — опции графика принимают строки цвета, styled
    `theme` туда не попадает сам: нужен `useTheme()` или импорт `theme`.
    Иначе — новые литералы в обход критерия 2.
12. **Оракул критерия 7 (те же EMA/BB).** Бэкенд округляет до 2 знаков
    (`market-data.service.ts:42-45`); если формат цены серии на графике
    будет другой точности, сверка «перекрестие = `/market/view`» даст
    ложные расхождения на отображении.
13. **Размер бандла** — +lightweight-charts, −recharts; измерить `npm run
    build` до/после (сейчас не замерено).
