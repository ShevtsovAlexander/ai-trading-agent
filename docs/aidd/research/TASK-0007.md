## Внешние API (curl 2026-10-27, без ключей)

### Funding — Binance USDⓈ-M (`fapi.binance.com`)
- `GET /fapi/v1/premiumIndex?symbol=BTCUSDT` → `markPrice`, `indexPrice`,
  `lastFundingRate`, `nextFundingTime` (мс), `time`. На момент замера:
  BTC 0,0081 %, ETH 0,0045 %, SOL 0,0082 %, `nextFundingTime` у всех
  1793116800000.
- `GET /fapi/v1/fundingRate?symbol=…&limit=1000` **без `startTime` вернул
  500 записей** (~167 дней), **с `startTime` — 1000** (~333 дня);
  `startTime=1700000000000` (ноябрь 2023) — тоже 1000 записей с того места.
  История глубже года, постранично.
- `GET /fapi/v1/fundingInfo` — `fundingIntervalHours: 8` у BTC/ETH/SOL,
  `adjustedFundingRateCap` 0,3 % (BTC/ETH), 0,375 % (SOL).
- Заголовок `x-mbx-used-weight-1m` в ответе `fundingRate` **не пришёл**
  (`curl -D`) — механика ограничителя из `market-data.service.ts:217-240`
  на fapi как есть не переносится.

Распределение последних 500 выплат (без `startTime`):

| Монета | макс | мин | доля ровно 0,0100 % | выше 0,0100 % |
|---|---|---|---|---|
| BTC | 0,0100 % | −0,0067 % | 11,4 % | 0 |
| ETH | 0,0100 % | −0,0118 % | 6,2 % | 0 |
| SOL | 0,0100 % | −0,0388 % | 15,8 % | 0 |

**Поправка к PRD («Риски», «потолок по умолчанию»):** 0,0100 % — не
потолок (cap по `fundingInfo` — 0,3 %), а значение, к которому ставка
прилипает при малой премии (базовая ставка, `interestRate` 0,0001 в
`premiumIndex`). За ~167 дней выше её не было ни у одной монеты — то есть
перекоса в лонг сильнее «нейтрального» не случалось. Вывод о мере
необычности остаётся: ряд несимметричен.

### Open interest — три биржи, разные единицы

| Биржа | Запрос | Поля | Единица OI | BTC, USD |
|---|---|---|---|---|
| Binance | `fapi/v1/openInterest?symbol=BTCUSDT` | `openInterest`, `time` | **монеты** (98 105,8 BTC) — USD = × `markPrice` из `premiumIndex` | ≈ 7,84 B |
| OKX | `api/v5/public/open-interest?instType=SWAP&instId=BTC-USDT-SWAP` | `oi` (контракты), `oiCcy` (монеты), `oiUsd`, `ts` | `oiUsd` готов | 2,62 B |
| Bybit | `v5/market/tickers?category=linear&symbol=BTCUSDT` | `openInterest` (монеты), `openInterestValue` (USD), `fundingRate`, `nextFundingTime`, `markPrice` | `openInterestValue` готов | 5,17 B |

Сумма BTC ≈ 15,6 B USD (у TradingView «по рынку» — 30,5 B). ETH:
Binance 2 367 876 ETH × 2315,97 ≈ 5,48 B, OKX 1,51 B, Bybit 1,85 B.
SOL: Binance 9 014 801 SOL × 100,10 ≈ 0,90 B, OKX 0,33 B, Bybit 0,60 B.
Символы фьючерсов: OKX `BTC-USDT-SWAP` / `ETH-USDT-SWAP` / `SOL-USDT-SWAP`,
Bybit — как Binance (`BTCUSDT`…).

Попутно: Bybit `tickers` несёт свою `fundingRate` (BTC 0,0100 %, ETH
0,0047 %, SOL 0,0003 %) — у бирж funding разный.

## Риски изменения
- **Три внешних хоста** (`fapi.binance.com`, `www.okx.com`, `api.bybit.com`)
  — каждый может быть недоступен по региону (как `api.binance.com`,
  `backend/CLAUDE.md`, «Известное»). Сейчас все три отвечают с этой машины.
- **Нет заголовка веса на fapi** — ограничитель из
  `backend/src/market/market-data.service.ts:217-240` опирается на
  `x-mbx-used-weight-1m`; без заголовка он «выключен» с `logger.warn`
  (`:218-226`). Если переиспользовать — предупреждение будет всегда.
- **Разные единицы OI** — Binance в монетах, два других в USD: сумма без
  перевода — ошибка в десятки тысяч раз (98 105 «как USD»).
- **Время у бирж разное** — `time`/`ts`/`nextFundingTime` у каждой свои;
  сумма OI складывает снимки разных моментов (секунды разницы).
- **Глубина `fundingRate` без `startTime` — 500**, а не 1000: период
  «нормы» длиннее ~167 дней требует `startTime` и нескольких страниц.
- **`App.tsx` уже 356 строк** и держит всю загрузку — встраивание ещё одного
  источника увеличивает связность (см. «Дальние связи», `load()`).
