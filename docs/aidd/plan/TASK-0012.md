# План: TASK-0012 — расширенный Daily Read

## Подход

Свод = **факты рынка, посчитанные кодом** + заголовки → модель пишет один
абзац → **код проверяет ответ** → свод вместе с фактами отдаётся фронту.

```
Binance klines 1h (31 день, 1 запрос/монета) ─┐
getRegime (кэш дня, TASK-0011) ───────────────┼→ buildFact ×3 ─┐
RSS-лента (как сейчас) ────────────────────────────────────────┼→ промпт → Groq
                                                               │      ↓
                                            checkSummary(текст, промпт) ── нет → прошлый свод
                                                               │ да
                                       Digest { summary, facts, … } → GET /news/digest → NewsPanel
```

- **Факты** (по монете): цена закрытия последнего часа, изменение за 24 ч
  (к закрытию часа на 24 ч раньше), объём за 24 ч в USDT (`quoteAssetVolume`
  — research: в монетах отношение другое), отношение к среднему суточному
  объёму 720 часов перед этим, режим и его дни (TASK-0011). Почему часы, а
  не дневки: свод раз в час, дневная свеча к вечеру устарела бы на сутки.
- **Проверка ответа** (нового в проекте нет — research): каждое число текста
  должно встречаться в промпте (факты + заголовки), слова-указания запрещены.
  Не прошёл — свод остаётся прошлым. Это внешний оракул «модель не выдумала
  числа», без модели в тесте.
- **Свод и факты — парой**: текст всегда показан с теми фактами, по которым
  написан. Модель недоступна/ответ отвергнут: есть прошлый свод — он; нет —
  свод с `summary: null` и текущими фактами (фронт покажет факты без текста).
- Свод строится и при пустой ленте (сейчас `news.service.ts:73` не зовёт
  `generate`); кэш — по хешу ленты **и фактов** (`digest.service.ts:28-29`
  смотрит только ленту).

## Контракты

```ts
// digest.types.ts
export interface MarketFact {
  coinId: string; market: string;       // 'BTC/USDT'
  price: number;                        // close последнего закрытого часа
  change24hPct: number;                 // (close / close 24 ч назад − 1)·100, 2 знака
  volume24hUsd: number;                 // Σ quoteAssetVolume 24 ч, USDT
  volumeRatio30d: number;               // volume24h / (Σ 720 ч перед ними / 30), 2 знака
  regime: 'up' | 'down' | 'range' | null; regimeDays: number | null; // null — режим не получен
  at: number;                           // closeTime последнего часа
}
export interface Digest {
  summary: string | null;               // null — текста нет (модель/проверка), факты есть
  generatedAt: string;                  // ISO, время сборки
  itemCount: number;                    // новостей в промпте (0 — свод по рынку)
  market: { facts: MarketFact[]; failed: string[] }; // failed — coinId без фактов
}
// market-facts.ts
export const HOURS = 744;               // 24 + 720
export function buildFact(coinId: string, market: string, hours: HourCandle[],
  regime: { regime: Regime; days: number } | null): MarketFact; // < 744 часов → throw
// check.ts
export function checkSummary(summary: string, prompt: string):
  { ok: true } | { ok: false; reason: string };
```

Числа в проверке: `\d+(?:[   ]\d{3})*(?:[.,]\d+)?` → без
пробелов, запятая → точка → `parseFloat`; допустимы те, что есть в промпте
(сравнение по значению: 0,30 = 0,3). Слова-указания: купить/продать
(и формы), покупай/продавай, рекоменд…, войти/входить (в позицию).

## Поток данных

- `NewsService.refresh` (cron час + старт) → `generate(лента)`.
- `generate`: факты трёх монет (`allSettled`: часы — обязательно, режим —
  нет: упал → `regime: null`); хеш(id ленты + факты); тот же → кэш; лента и
  факты пусты → прошлый; промпт; `complete`; `checkSummary`; ок → новый свод;
  нет/ошибка/пусто → прошлый свод, а без прошлого — `summary: null` + факты.
- Запросы к Binance: 3 в час (вес 2 каждый), режим — из кэша дня.

## Trade-offs

1. **Часовые свечи своим запросом, а не `fetchClosedCandles`.** Ему нужен
   `k[7]`, а `Candle` уходит в `/market/candles` — менять форму ответа и
   фикстуры ради свода не стоит. Цена — второй разборщик klines (в проекте
   уже есть дубль в бэктесте).
2. **Проверка ответа кодом строгая**: честный пересказ «втрое» отвергнется.
   Лучше показать прошлый свод/только числа, чем выдуманное число.
3. **Не причинность**: промпт запрещает «из-за/потому что» между новостью и
   движением? — нет, запретить слова нельзя надёжно; промпт просит не
   связывать причинно, проверка — только числа и указания.
4. **Свод общий на три монеты** (вкладка «Инфополе» общая), не по монете.
5. **Без модели живьём** (403): живая сверка — только факты; текст — человек.

## Риски

- Модель недоступна в окружении агента — путь `summary: null` будет
  основным при живой проверке.
- Строгая проверка может держать свод прошлым часами — видно по времени.
- 744 закрытых часа без дыр Binance — допущение; дыра (остановка биржи)
  сдвинет «24 ч назад» на час. Проверка: шаг соседних часов; есть дыра —
  факт по фактическим 24 строкам, не по времени (принято, подпись времени).
