# План: TASK-0013 — компании-держатели + таймаут модели

## Подход

**А. Компании-держатели.** Модуль `treasury/`: CoinGecko
`companies/public_treasury/{id}` (строгий разбор) → снимок по монете на 1 ч
(и ошибка — 60 с) → `GET /treasury/:coinId`. Доля = `totalHoldings /
circulating` из `CoinService` (тот же знаменатель, что карточка «Монета»;
у CoinGecko `percentage_of_total_supply` для BTC — от 21 млн, для ETH — от
обращения: смешивать нельзя). `CoinService` упал — доля `null`, остальное есть.
Фронт — блок под «Монетой», опрос 10 мин.

**Б. Таймаут модели.** (1) `AiService`: `timeout` и `maxRetries` клиента Groq
из конфига (`GROQ_TIMEOUT_MS` по умолчанию 20 000, `GROQ_MAX_RETRIES` — 1)
вместо 60 с × 3. (2) `MarketComment.describeView`: ждёт генерацию не дольше
`VIEW_COMMENT_WAIT_MS` = 3000; не успела — прошлый комментарий ключа или
`null`, генерация продолжается и пишет кэш; одна генерация в полёте на ключ
(опрос не плодит параллельные вызовы).

## Контракты

```ts
// treasury/treasury.types.ts
export interface TreasuryCompany { name: string; symbol: string; country: string;
  holdings: number; valueUsd: number }
export interface Treasury {
  coinId: string; market: string;
  totalHoldings: number; totalValueUsd: number; companies: number;
  shareOfCirculatingPct: number | null;   // totalHoldings / circulating · 100, 2 знака
  top: TreasuryCompany[];                 // 5 крупнейших по holdings
  fetchedAt: number;                      // момент ответа CoinGecko, мс
}
// GET /treasury/:coinId → Treasury; 400 — монета; 502 — «CoinGecko недоступен» / «… лимит»
```

## Trade-offs
1. **Без ETF** — источника нет; честнее не показывать, чем парсить вёрстку.
2. **Доля своим знаменателем** — единое определение для трёх монет.
3. **Кэш 1 ч** — данные меняются с отчётами компаний; лимит CoinGecko общий.
4. **Таймаут в `MarketComment`, а не отдельный маршрут** — фронт не меняется,
   поведение «комментарий догоняет опросом» уже поддержано (`aiComment: null`).

## Риски
- Окно 3 с: на медленной модели первый показ без комментария.
- `maxRetries 1` — перевод и свод в фоне чаще будут падать на сбое Groq;
  у обоих есть fallback.
