# План: TASK-0017 — «Открытые позиции» глубже 30 дней (1Г и «Всё»)

PRD — `docs/aidd/prd/TASK-0017.prd.md`, research — `docs/aidd/research/TASK-0017.md`.

## Подход

Тот же маршрут и та же карточка, новый параметр периода. 30Д не меняются: те же запросы к биржам и сборка
`buildOiSeries` (research, «Как устроены смежные части»). 1Г и «Всё» строятся из одного дневного запроса
Coinalyze на монету: 3 символа, `convert_to_usd=true`, с 2022-09-30. 1Г — последние 365 точек того же ряда.
Цена — дневные свечи спота Binance, как сейчас.

Две поправки из замера research:
- **момент точки = метка Coinalyze + сутки**: бар `D 00:00` содержит значение на конец дня, у нас это момент
  `D+1 00:00`;
- **бар, чей момент ещё не наступил** (живой текущий день), отбрасывается.

Фронт узнаёт, задан ли ключ, из ответа 30Д: его грузят всегда первым. Отдельного запроса нет.

## Контракты

```ts
// derivatives.types.ts (зеркало — frontend/src/types/derivatives.ts)
export type OiPeriod = '30d' | '1y' | 'all';

export interface OpenInterestHistory {
  coinId: string;
  market: string;
  period: OiPeriod;                 // новое
  step: OiStep;                     // на 1y / all всегда '1d'
  source: 'exchanges' | 'coinalyze'; // новое: 30d — биржи, 1y / all — Coinalyze
  longAvailable: boolean;           // новое: задан ли ключ Coinalyze (фронт гасит 1Г / «Всё»)
  exchanges: (...)[];               // как сейчас; у Coinalyze — «нет данных Coinalyze»
  priceError: string | null;        // как сейчас
  points: OiPoint[];                // как сейчас: t — момент снимка, byExchange — USD
}
```

`GET /derivatives/:coinId/open-interest?period=30d|1y|all&step=1d|1h`:
- `period` не задан → `30d`: старые вызовы работают как раньше.
- `1y` / `all` с `step=1h` → 400 «Почасовой шаг — только 30 дней»; `step` не задан → `1d`.
- Неизвестный `period` → 400.
- `1y` / `all` без ключа → 502 с текстом ликвидаций «Не задан ключ Coinalyze (…)».
- 401/403 → 502 «Coinalyze отклонил ключ», 429 → 502 «Coinalyze: превышен лимит запросов», иначе → 502
  «Coinalyze недоступен». Тексты — как `liquidations.service.ts:26-29,169-194`.
- Символа нет в ответе или пустой ряд → у биржи `{ exchange, error: 'нет данных Coinalyze' }`, биржа выпадает из
  суммы всех точек, как в 30Д (`oi-history.ts:21-22`).
- Спот упал → `priceError: 'Binance недоступен'`, ряд OI цел.

```ts
// oi-long.ts
export const OI_LONG_FROM = Date.UTC(2022, 8, 30);    // первая метка в USD у всех 9 рядов (research)
export function parseOiHistory(raw: unknown, symbols: string[]): Map<string, { t: number; usd: number }[]>;
export async function fetchOiHistoryCoinalyze(http, key, symbols, from, to): Promise<Map<...>>;
export function buildOiLongSeries(input: {
  period: '1y' | 'all'; now: number;
  rows: Partial<Record<Exchange, { t: number; usd: number }[]>>; // только ответившие биржи
  spot: Candle[] | null;

```

`buildOiLongSeries`: момент `= t + DAY`; моменты `> now` отброшены; точка — только при всех ответивших биржах;
цена — close свечи, открытой в `момент − DAY`; `1y` — последние 365 моментов, `all` — все.

## Поток данных

```
фронт: период 30Д ──► ?period=30d&step=1d|1h ──► биржи (как сейчас) ─► + longAvailable
фронт: 1Г / Всё ───► ?period=1y|all ─► ключ? ─нет─► 502 «нет ключа»
                                        │да
                                        ▼
                     кэш «монета» (один ряд на 1Г и Всё) ─ промах ─► Coinalyze: 1 запрос, 3 символа
                                                                     Binance klines 1d: 2 страницы
                                        ▼
                     buildOiLongSeries ─► срез 365 / весь ─► ответ
```

Кэш: полный ряд (все три биржи, последний момент = сегодня 00:00 UTC, без дыр) — до следующей полуночи UTC +
10 мин, как `OI_PUBLISH_MARGIN_MS` (`derivatives.service.ts:51`). Неполный и ошибка — 60 с (`OI_RETRY_MS`,
`:52`). Один запрос в полёте на монету. Нагрузка Coinalyze: ≤ 3 запроса в сутки при полном ряде, при ошибке ≤ 1
в минуту на монету.

## Trade-offs

1. **Тот же маршрут с `period`, а не новый.** Ответ той же формы, карточка и хук те же; `period` по умолчанию
   `30d` — старые вызовы не ломаются. *Отвергнуто:* отдельный маршрут — второй хук и второй тип ради тех же
   точек.
2. **1Г — срез «Всё».** Один запрос Coinalyze на монету в сутки на оба периода. *Отвергнуто:* два запроса с
   разным `from` — двойной расход лимита без выигрыша (ответ «Всё» — 1502 бара).
3. **Лимит — своя пауза в деривативах, без общего модуля Coinalyze.** Research, риск 3: пауза ликвидаций —
   приватное поле. OI добавляет ≤ 3 запроса в сутки, так что общий счёт не нужен. *Отвергнуто:* вынести клиент
   Coinalyze в общий модуль — правка ликвидаций в том же тикете (VISION: «не рефактори и не добавляй фичи
   одновременно»). *Цена:* если лимит выбьют ликвидации, OI узнает это своим 429 и встанет на паузу сам.
4. **Символы — `LIQUIDATION_SYMBOLS`** (`liquidations.types.ts:7-23`), импорт из модуля ликвидаций. Те же символы
   уже сверены (research). *Отвергнуто:* копия — две таблицы символов разъедутся.
5. **`longAvailable` в ответе 30Д.** Фронт и так грузит 30Д первым. *Отвергнуто:* отдельный маршрут «есть ли
   ключ» — лишний запрос; узнавать по 502 ликвидаций — связь двух карточек.
6. **Шаг на 1Г / «Всё» спрятан, а не погашен** (PRD: «только на 30Д»). Выбранный шаг 30Д запоминается: вернулся
   на 30Д — тот же шаг.
7. **Подписи.** Заголовок «Открытые позиции» без «· 30 дней». Под графиком на 1Г / «Всё» — «Binance + OKX + Bybit —
   не весь рынок · Coinalyze · с 30 сент. 2022», дата — первая точка ответа. Ссылка Coinalyze, как у ликвидаций:
   условие бесплатного API (`frontend/CLAUDE.md`, «Ликвидации»). В легенде на 1Г / «Всё» — дата с годом.
   Оговорка та же.
8. **Шкала линейная** (PRD, «Масштаб»).

## Риски (research, «Риски изменения»)

- **Сдвиг метки** (риск 1). Защита — эталон Python и живая сверка 1Г с биржами 30Д на общих днях (PRD 2).
- **Живой бар** (риск 2) — отбрасывается по моменту. Когда Coinalyze дописывает вчерашний бар после 00:00 UTC,
  не замерено: запас 10 мин перенесён с OKX. Задача 17.3 сравнивает два снимка вчерашнего бара.
- **SOL Binance 2,96 %** (риск 8) — расхождение и со сдвигом. Подпись источника обязательна; число записать в
  RESEARCH, на стыке 30Д и 1Г разница видна.
- **Кэш полноты** (риск 5) — своя проверка: 365 / все моменты от первой точки, без дыр.
- **`fitContent`** (риск 6) — ключ карточки получает период.
- **Таймаут** (риск 4) — 10 с на модуль деривативов задевает и запросы к биржам 30Д. Они сейчас без таймаута;
  10 с — больше их обычного ответа. Проверка — живые 30Д в 17.3.
